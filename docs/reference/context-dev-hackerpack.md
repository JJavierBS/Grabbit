# Context.dev API Credits

by Context.dev

## Description

**Context.dev API access:** Every team gets **50,000 free API credits with no expiry** to bring live web data into their project. Context.dev turns websites, brands, companies, people and news into **clean, structured data** your app or AI agent can use.

Search and scrape pages, extract JSON with your own schema, get company and brand data, or set up monitors and webhooks to react when something changes. SDKs are available for **TypeScript/Node, Python, Ruby and Go**, alongside an MCP server for coding agents.

**No credit card needed.** Teams can run up to **50 concurrent requests**. Context.dev engineers will be on site to help you get started.

## Insights

### Getting started with Context.dev

1. Create an account at [context.dev/signup](https://context.dev/signup).
2. Redeem code **`JUNCTION26`** at [Redeem credits](https://context.dev/dashboard/redeem-credits) to receive **50,000 API credits per team, with no expiry**.
3. Copy your secret key from the [API keys page](https://context.dev/dashboard/api-keys).
4. Install the SDK with `npm install context.dev` or `pip install context.dev`.
5. Follow the [Quickstart](https://docs.context.dev/quickstart) to scrape your first page. Then try search, structured extraction, brand data, news or monitors in your project.

**Using a coding agent?** Follow the [Agent quickstart](https://docs.context.dev/agent-quickstart), or connect the MCP server at `https://mcp.context.dev/mcp` using the [setup guide](https://docs.context.dev/install-mcp).

**Need fresh data?** Results are cached for up to 3 days by default. Set `maxAgeMs: 0` when you need a fresh copy. Check each output's `success` flag before using its data.

**Need help?** Visit the Context.dev booth or contact **[beer@context.dev](mailto:beer@context.dev)**. Full documentation: [docs.context.dev](https://docs.context.dev/).
