# Retrieve credit usage

> Retrieve your organization’s credit balance, current-period usage, and next refill.

0 credits

Requires [`logs:read` permission](https://docs.context.dev/account/api-keys). See the [guide](https://docs.context.dev/optimization/usage-and-logs.md) for examples and usage.
