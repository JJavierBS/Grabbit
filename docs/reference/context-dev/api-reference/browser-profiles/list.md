# List browser profiles

> List the browser profiles your organization created with /web/scrape, newest first.

0 credits

Requires [`logs:read` permission](https://docs.context.dev/account/api-keys). See the [guide](https://docs.context.dev/scrape/browser-profiles.md#list-profiles) for examples and usage.
